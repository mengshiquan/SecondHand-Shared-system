# 开题报告

## 课题名称
校园二手物品共享平台的设计与实现

## 课题背景与意义

随着高校招生规模持续扩大，校园内学生群体的闲置物品交易需求日益增长。每年毕业季，大量教材、电子产品、生活用品被低价处理或丢弃，造成资源浪费。与此同时，在校学生对高性价比二手商品存在刚性需求。

传统的校园二手交易主要依托QQ群、微信朋友圈、贴吧等社交平台，存在以下突出问题：信息碎片化导致商品难以检索筛选；买卖双方身份不透明，信任机制缺失；缺乏统一的订单管理和状态追踪机制；买方无法参考历史交易记录判断卖家信誉。

本项目构建一个面向高校校园的专属二手物品共享平台，具有经济价值（促进闲置物品循环利用，降低学生生活成本）、社会价值（践行绿色校园理念，减少物品浪费）和技术价值（实践前后端分离架构、JWT无状态认证、RESTful API设计等现代软件工程方法）。

## 国内外研究现状

目前，国内外二手交易平台发展迅速，但专门针对校园场景的二手交易系统研究相对较少。主流二手交易平台如闲鱼、转转等面向全年龄段用户，校园场景的特殊性未得到充分关注。

校园二手交易平台具有以下特点：用户群体相对封闭（仅限校内师生）；交易商品以学生刚需为主（教材、电子产品、生活用品）；交易金额普遍较低；用户之间的信任关系相对容易建立。

现有校园二手交易主要依托QQ群、微信朋友圈、贴吧等社交平台，存在信息分散、交易流程不规范、评价体系缺失等问题。本课题研究正是针对这些痛点，设计与实现一套专门的校园二手物品共享平台。

## 课题研究内容

本课题研究内容主要包括以下几个方面：

**系统需求分析**：调研校园二手交易的实际需求，明确目标用户群体，确定系统的功能需求和非功能需求，设计用户角色（游客、普通用户、管理员）和功能模块。

**系统架构设计**：采用前后端分离架构，后端基于Spring Boot框架，前端基于Vue.js框架，数据库采用MySQL，设计清晰的分层架构（控制层、业务层、数据访问层）。

**核心功能实现**：实现用户认证模块（注册、登录、JWT令牌管理）；商品管理模块（发布、编辑、删除、查询）；订单管理模块（创建订单、状态流转、取消订单）；收藏与评论模块；后台管理模块（数据概览、用户管理、商品管理）。

**系统测试验证**：编写功能测试用例，验证系统各项功能的正确性；进行前端可视化验证，确保用户界面友好美观。

## 课题预期目标

本课题预期达到以下目标：

1. 完成校园二手物品共享平台的需求分析，编制详细的需求规格说明书
2. 设计并实现一套完整的Web应用系统，包括前端界面和后端服务
3. 实现用户认证、商品发布与管理、订单流转、收藏评论等核心功能
4. 提供友好的用户界面和良好的用户体验
5. 编写规范的毕业论文文档

## 课题拟解决的关键问题

1. **无状态认证方案**：采用JWT实现无状态认证，解决分布式环境下的用户身份验证问题
2. **商品状态管理**：设计合理的状态机模型，管理商品的上下架状态
3. **订单状态流转**：设计完整的状态流转机制，确保订单状态的正确转换
4. **权限控制**：实现基于角色的访问控制，确保不同角色用户的操作权限
5. **前后端数据交互**：设计统一的RESTful API接口，实现前后端高效数据交互

## 研究方法与技术路线

**研究方法**：
- 文献研究法：查阅相关技术文档和最佳实践
- 面向对象分析法：分析系统需求，设计类模型
- 原型法：快速迭代开发，及时获取用户反馈

**技术路线**：
- 后端：Spring Boot 3.3.5 + MyBatis-Plus 3.5.9 + MySQL 8.0 + JWT
- 前端：Vue 3 + Vite 5.x + Element Plus + Pinia + ECharts
- 开发流程：需求分析 → 架构设计 → 编码实现 → 测试验证
